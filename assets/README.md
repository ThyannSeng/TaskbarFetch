# TaskbarFetch icon

The TaskbarFetch application icon is an original project asset created for TaskbarFetch.

- Copyright: © 2026 Thyann Seng
- License: MIT, as part of this repository
- Source generator: `generate_icon.py`

To regenerate the PNG and ICO files:

```powershell
py -m pip install pillow
py assets/generate_icon.py
```

The icon is intentionally built from simple geometric primitives so its provenance is reproducible directly from repository source.

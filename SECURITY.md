# Security Policy

## Supported version

Security fixes are applied to the latest release of TaskbarFetch.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** feature if it is enabled for the repository.

If private vulnerability reporting is not available, open a public issue that asks the maintainer for a private contact channel. Do not include exploit details, sensitive data, or proof-of-concept code in that public issue.

TaskbarFetch is intentionally local-only. It does not require a server, does not send telemetry, and does not need administrator privileges for normal use.
